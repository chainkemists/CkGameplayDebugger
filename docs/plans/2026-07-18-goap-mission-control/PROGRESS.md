# GOAP Mission Control — port the mockup to the in-engine debugger

**Living doc.** Update the status board + session log every session; decisions are numbered and
appended, never rewritten. A fresh session resumes from here.

## Goal (verbatim intent)

Deprecate the existing GOAP debugger UI and replace it with the **Mission Control** design
(`Source/CkGoapDebugger/Mockups/mockup_d_mission_control.html` — open it in a browser; it is
live/interactive and is the visual + feature spec). Requirements:

1. **Every feature in the mockup ships** in the Unreal debugger.
2. **Visual parity as close as Slate allows** — including underlines, borders, glows, dim chip
   backgrounds, rounded corners, accent treatments.
3. **All visuals via common widgets** — upgrade existing `CkDebuggerCommon` widgets or add new
   common widgets when none exists. No bespoke one-off styling buried in the GOAP module.

## Decisions

- **D1 — Reuse the data plumbing, replace the UX.** ViewModel/DataCollector/HistoryModel and the
  UEdGraph plan graph stay (extended); every window panel is rebuilt to the mockup layout. The
  lifecycle contracts (EndPIE handle clearing, OnEnginePreExit teardown) carry over untouched.
- **D2 — Tokens stay in `CkStyle::`; shared brushes/widget styles go in a NEW
  `FCkDebuggerCommonStyle` style set in CkDebuggerCommon.** The GOAP-local
  `FCkGoapDebuggerStyle` palette is retired; GOAP keeps at most graph-node-specific brushes.
  Accent default flips amber → `#54C6FF` (mockup telemetry cyan); add per-tone Dim colors
  (`GetToneDimColor`), `AccentDim`, glow tokens, `MonoFont(Size)`/`BoldFont`/`UIFont` helpers.
  Existing debuggers keep compiling and simply get the new accent (user-tunable if they object).
- **D3 — Glow = pre-generated monochrome soft-glow 9-slice PNGs** under
  `CkDebuggerCommon/Resources/`, registered by the common style set, tinted at runtime
  (active-chain cyan, fallback amber). Generated by `docs/plans/.../generate_glow.ps1`, committed.
- **D4 — Decision-panel scoring runs debugger-side** (pure functions over collected
  `FActionDef` mirrors + the WS bool map): viability, unmet keys, forced-first total (mini
  regressive A* mirroring `ck::goap` — ≤64 keys, tiny catalogs), cross-tier notes (sub-planner
  cost with/without a candidate's effects), catalog lint (cross-tier reachability, dead effects).
  Unit-tested like `HistoryModel.spec.cpp`. No engine what-if API.
- **D5 — Engine hooks are additive and minimal** (CkGoap): Utils getters for the params block;
  `FFragment_Goap_Planner_ReplanCause` (source enum + changed keys old→new + coalesced count +
  world time) written by AutoReplan/HandleRequests + `Get_LastReplanCause`;
  `Get_LastSearchDebug(Planner)` (display-friendly copy of StatePool/EdgeActions/g/h + expanded
  count, pool size, slice count, elapsed µs — add counters to the A* search state if absent).
  Three-environments rule applies (UFUNCTION → BP + AS).
- **D6 — Sandbox/cost-edit/pause-on are live engine behaviours, not simulations.** Sandbox =
  existing DebugUI layer (WS-dirty → real replans; show shared-WS blast radius from subscriber
  count). Cost stepper = `Request_SetChildActionCost` + follow-up `Request_Plan` when the
  policy wouldn't auto-replan. Pause-on-event = ViewModel auto-freeze (switch to Scrub at the
  matching history event); PIE-pause optional stretch.
- **D7 — REC = history-recording toggle** (collector already records continuously); off = stop
  appending + clear on demand. Timeline scrub = existing Scrub mode over the ring.
- **D8 — Branching:** CkGameplayDebugger work on `feature/goap-mission-control` (branched off
  `a522b80`); CkFoundation (CkGoap + CkEditorTools) commits on `dev` per that repo's convention.
  Push only when asked.

## Feature checklist (from the mockup — every box must tick before "done")

Chrome: agent picker, planner picker (+sub count), LIVE/PAUSED pill, step back/fwd, REC,
nerd-mode toggle. Nerd strip: plan µs, budget bar + slices, states expanded, pool, gate note,
entity handles. Alert strip: fallback-active warn (+fix hint), sandbox banner (+blast radius,
pop button). Tabs: Squad (count), Agent Inspector, Catalog Audit (warn dot).
Inspector left: agent card (avatar, class, status pill, attempt #), chain breadcrumb (role
glyphs, glow leaf, fallback tint), Goal panel (live satisfaction), Plan panel (step cards, NOW
marker, sub-plan nesting, fallback note, costs, footer), Settings drawer (all 10 params, RO
locks, tooltips, Replan/Cancel/Reset/Disable buttons), Invalid-goal diagnostics row.
Center: Decision groups (in-plan/viable/blocked/fallback ordering, why-line with forced-first Δ,
unmet keys bold, cost stepper + edited badge + reset, cost bar, cross-tier tip notes, sub-planner
section incl. dormant state), Plan graph (tree edges, active-chain glow, pre dots live, eff
line, role glyphs, costs, hover tooltips), Search trace (regressive explanation, constraint-set
rows, via-action, g/h, satisfied-row highlight, truncation note; nerd-gated).
Right: WS panel (usage nP·mE chips, value pills, sandbox editability, shadow badge "DebugUI",
"just changed" note, click-to-trace highlight across all panels, layer stack + depth, key budget
n/64, subscriber count, trace-hint footer).
Timeline dock: lanes (WS/REPLAN/ACTIVE), tick axis, WS-change squares, coalesced ×2 marker,
replan diamonds (selectable), activation bar, jump-to-replan buttons, pause-on checkboxes,
diff card (trigger incl. cause + coalescing + policy, old→new plans, Δ cost verdict), event log
(time, type chips WS/RP/SIG, plain-language lines, click-to-scrub, selection highlight).
Squad: one row per planner world-wide (avatar, name, planner tag, status pill incl. Planning/
Disabled/PlanFailed/CostThreshold, active chain, plan cost, attempts, replans-60s sparkline,
alert tags, Inspect action). Catalog: action cards (class + derived tag, cost stepper, badges
sub-planner/fallback/cost-provider, pre/eff chips, ⋯ runtime add/remove affordance), health
checks (fallback guarantee, no cycles, goal keys registered, key budget meter, cross-tier
reachability INFO, dead-effect INFO), key⟷action matrix (P/E cells, goal badge, active-chain
column glow, click-key trace).
