CkGoapDebugger — PrimaryPane mockups

Three alternative layouts for the planner-detail view. All three apply the same color/contrast fixes (tier pills, brighter inactive crumbs, brighter separator). Pick the layout direction; the contrast fixes carry across.

A — Hero header
single-column · side-by-side plan + diagnostics
Boxed hero block groups identity + the 4 quick-stats. Right-rail metadata absorbed inline next to PLAN. No orphan side column.
  • Best when most planners have ≤ 5 plan steps
  • Single-step (current screenshot) reads as deliberate, not empty
B — Dashboard 2×2
grid · four labelled quadrants
Each quadrant does one job: Identity, Plan, Goal, Diagnostics. Easiest to scan visually; hard separation between "what is this" and "what's it doing."
  • Best when you want hard separation between sections
  • Worst when a plan grows past ~4 steps (top-right squeeze)
C — Vertical sections
single-column · collapsible groups
PLAN / GOAL / WIRING / DIAGNOSTICS stacked, each collapsible. Diagnostics default-collapsed (usually green). Works at any plan size.
  • Best when panes get embedded in tight columns
  • Worst when you want metadata in your peripheral vision

Color / contrast fixes — applied to all 3

  • Breadcrumb tier (T0, T1) — now a small rounded chip with a subtle blue tint, not raw muted text. Reads as a deliberate UI element.
  • Inactive crumb — text bumped from Color_Text_Dim (#666) to Color_Text_Secondary (#aaa), italicized. Active crumb keeps the amber border so the contrast is "border + primary" vs. "no border + secondary italic".
  • Crumb separator (>) — bumped from Color_Text_Ghost (#444) to Color_Text_Muted (#888). Was almost invisible at the chosen size.
  • Right-rail values (where present) — labels stay 8pt muted-uppercase; values bumped to 10pt regular primary color.
