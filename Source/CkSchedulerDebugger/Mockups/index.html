Processor Scheduler Debugger — Mockups

Click a mockup to open it. Each is a self-contained interactive prototype.

Mockup A
Classic Tri-Pane
Three-pane split: processor tree on the left, tabbed content area (tree detail + graph) in the center, details panel on the right. Follows the existing ECS Debugger layout pattern.
+ Familiar layout + Tree scales well + Proven pattern - Tree/graph not simultaneous Navigation-first
Mockup B
Graph-Centric
Full DAG graph as the hero view with a collapsible sidebar for search, stats, and details. Groups as bounding boxes. No separate tree — the graph IS the navigation.
+ Max graph space + Dependencies visible + Heat map overlay - 260+ nodes needs zoom Structure-first
Mockup C
Execution Timeline
Waterfall/profiler view with horizontal bars proportional to execution time. Groups as swim lanes. Pump passes extend the timeline. Instant hotspot detection.
+ Timing at a glance + Profiler-like + Pump flow visible - Deps need overlay Performance-first
UNIFIED
Combined: Tree + Timeline (with tabs)
Three tabs in one tool: Tree View (Mockup A), Timeline (Mockup C), and Combined (both views with toggleable split). Shared selection state across all tabs. This is the chosen direction.
+ Best of both worlds + Shared selection + Flexible layout 3 viewing modes
